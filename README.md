# Модель сервиса конвертации файлов

Проектирование системы массового обслуживания для варианта 26. Заявки на конвертацию файлов поступают от источника, ожидают в ограниченном буфере и обрабатываются свободными обработчиками. Работа системы представлена диаграммами последовательности, классов и процесса обработки событий.

## Вариант 26

**ИБ | ИЗ2 | ПЗ1 | Д1ОЗ3 | Д1ОО4 | Д2П2 | Д2Б3 | ОР1 | ОД2**

| Код | Правило модели |
| --- | --- |
| ИБ | Бесконечный источник заявок |
| ИЗ2 | Равномерное распределение интервалов между поступлениями |
| ПЗ1 | Экспоненциальное распределение времени обработки |
| Д1ОЗ3 | Новая заявка занимает первое свободное место буфера; остальные заявки не сдвигаются |
| Д1ОО4 | Если буфер заполнен, вытесняется заявка, поступившая в него последней; новая занимает её место |
| Д2П2 | Свободный обработчик выбирается по кольцу |
| Д2Б3 | Ожидающая заявка выбирается из буфера по кольцу |
| ОР1 | В автоматическом режиме выводится сводная таблица результатов |
| ОД2 | В пошаговом режиме выводятся схема и текущее состояние модели |

## Как работает модель

Источник создаёт заявку на конвертацию и планирует поступление следующей. Диспетчер постановки ищет первое свободное место в буфере. При переполнении он вытесняет последнюю поступившую в буфер заявку и учитывает её как отказ.

После постановки заявки в буфер диспетчер выбора ищет свободного обработчика и ожидающую заявку. Для этих двух поисков используются независимые циклические указатели. Если все обработчики заняты, заявка остаётся в буфере. Когда обработчик завершает работу, диспетчер выбора снова проверяет буфер и при возможности назначает ему следующую заявку.

Отказы возникают при переполнении буфера. Занятый обработчик заявку не отклоняет.
